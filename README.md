📌 Project Overview

During my internship at Keystone, I was tasked with developing a dynamic website to assess a company’s security level against ransomware attacks. The goal of this project was to provide organizations with a structured way to evaluate their current defenses, identify vulnerabilities, and receive actionable recommendations for improvement.

⚙️ How It Works

The project is divided into two main steps:

1️⃣ Equipment & Technology Assessment

Identify all equipment and technologies used by the company.

Evaluate whether each is adequately secured against ransomware.

Generate a detailed report that:

Lists missing or weak security measures.

Provides step-by-step recommendations.

Assigns a security score based on the percentage of implemented defenses.

2️⃣ Ransomware Technique Defense Evaluation

Assess the company’s readiness against various ransomware attack techniques.

Match each attack method with appropriate countermeasures.

Generate another report that:

Highlights unimplemented measures.

Provides a second security score reflecting the company’s preparedness.

📊 Final Output

The website then combines both assessments into an overall security score, giving a clear picture of the company’s defense level against ransomware.
